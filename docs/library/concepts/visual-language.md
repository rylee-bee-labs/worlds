If every breakable wall has the same crack, players learn to spot cracks.
You taught them something without a single word.

That's **visual language**: using a look consistently, so it comes to mean
something.

* * *

It only works if it's kept. One crack that *doesn't* break teaches players
to stop trusting cracks.

* * *

## Words to know

- **Visual language:** a consistent look with a learned meaning.
- **Consistency:** the same thing looks and works the same way everywhere.
- **Convention:** a look that most games or apps already use, so people arrive knowing it.

* * *

## Under the hood

In Worlds, design tokens are visual language for the screens: the same name
always means the same color or space.
