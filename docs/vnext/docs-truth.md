# Docs truth — the canonical pointer table

> **Status:** Current · **Verified:** 2026-10-13 · **Canonical for:** which file owns which command and claim, and which docs are superseded · **Read this if:** a doc told you something that the code no longer does, or you are about to hand-copy a route list, a build step or a test result into a page.

**In short:** one short table of pointers. It does not restate routes,
commands or receipts — it names the file that already owns each one, so
there is exactly one copy of every claim in the repository. If two docs
disagree, the owner named here wins and the other is drift.

This file is a router, not a census. Generated inventories
(`scripts/gen-openapi.py`, `scripts/contract-drift-check.py`,
`scripts/route-inventory.json`) and the per-page status lines remain the
source; this page only says which is which.
