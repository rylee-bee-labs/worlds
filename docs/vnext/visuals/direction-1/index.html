Worlds visual direction 1 — the shoreline MOCKUP

The shoreline, at both widths

Four states, one responsive page each. The phone frame is the page at 390 px. The wide frame is the same file at 1440 px — it scrolls sideways inside its own frame, so this page itself never scrolls sideways.

MOCKUP — not a prototype, and not approved. Every service, owning system and address below is invented for the mockup. Nothing was fetched from a provider and no value shown is a real result. Outbound links point at reserved .invalid addresses.
