# T3: whole-world strip and Home
Depends on T2 (Row, Meter) being applied. Read `briefs/COMMON.md`, `ui/src/fd/{api,home-model,prefs}.ts(x)`, `ui/src/fd/Row.tsx`, `ui/src/test/fd-home.test.tsx`.

Create `ui/src/fd/Strip.tsx`: `Strip({ rows, onSelect })`, `rows: Row[]` (type from home-model; alias the import to avoid clashing with the Row component), `onSelect(cardId: string): void`. A `<div role="group" aria-label="Whole world">` with one control per source: icon (decorative), name, state shape + word. At least 56px tall; wraps; a 4-column grid below 600px.
- Normal sources: `<button>`, accessible name exactly `{title}: {State word}. Show details`.
- `not_configured` sources: an `<a href="#connect">`, accessible name exactly `{title}: Not configured. Set up in Connect`, shape ◇.

Create `ui/src/fd/Home.tsx`: `Home({ timeZone })`. Uses `useHomeData()` and `usePrefs()`. Call `buildSections(board, cards, needsYou)`. Structure, in this order inside one wrapper: `<h1>Home</h1>`, a paragraph with the briefing, the Strip (all visible items: the rows of needs_look, your_life, quietly_working and not_configured, in board order), a quiet `<button>Edit Home</button>` (does nothing yet), then sections each with an `<h2>`: Needs you, Needs a look, Your life, Quietly working (`SECTION_TITLE`). **Pick up is omitted entirely** (no heading, no line) because it has no data yet.
- Needs you: a `<ul>` of the `needsYou` entries, one `<li>` each: the text, the source name, and an action. `kind: "open"` → `<a href>` with accessible name `Open: {text}` (visible text "Open"). `kind: "approve"` → `<button>` with accessible name `Approve: {text}` (visible text "Approve"; it does nothing yet). Empty list: the section and heading stay, with "Nothing for you right now."
- Needs a look, Your life, Quietly working: a `<ul>` of `Row`s. Empty Needs a look shows "Nothing needs a look. Everything is answering." Empty Your life / Quietly working sections are omitted (no heading).
- `not_configured` sources are never rows.
Drill-in: state `openId: string | null`; clicking a row's button or a strip button sets/clears it; only one is open; the strip click opens the matching row's drill-in (rendered by Row with `expanded`). `buildSections` must be computed once per data load, never recomputed because of focus or openId changes (`useMemo` on the data).
Cards that failed (`failed` ids from `useHomeData`) become a synthetic envelope: `source_state: "unknown"`, `freshness: "stale"`, empty values, `meter: null`, last_good_at null, meaning short = the item title, evidence with request id `board.<card>` and `error_class: "connection"`. They show "—" and Unknown, never 0, and land in Needs a look. Loading shows one polite line "Loading Home". A board load error shows "Home could not load. Try again." with a "Try again" button.
Quiet group in Calm density: Quietly working rows fold into one line ("N quiet: names, comma separated") with a button to expand them.
Styles in `ui/src/fd/fd.css` under `/* home */` (shared: append).

Acceptance: `cd ui && npx vitest run --project unit src/test/fd-home.test.tsx`
