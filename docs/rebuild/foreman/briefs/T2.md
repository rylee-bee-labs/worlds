# T2: meters and row
Read `briefs/COMMON.md`, `ui/src/fd/types.ts`, `ui/src/fd/fixtures.ts`, `ui/src/test/fd-row.test.tsx`.

Create `ui/src/fd/Meter.tsx`: `Meter({ meter, frozen })`. `meter: Meter | null` (the type from types.ts; import it with an alias to avoid a name clash). Null renders nothing. Otherwise render one element with `role="img"`, `aria-label={meter.text_equivalent}`, `data-frozen="true"` only when frozen. Draw all seven types with plain divs/spans or inline SVG: segments, bars, progress, marks (only `shown` marks, then the text `+N more` when `more > 0`), dots, day (a track with labelled events; labels are visible text under the track), shelf (item titles as small text). A frozen meter uses a striped background (`repeating-linear-gradient`) and a dashed edge. Meters never animate.

Create `ui/src/fd/Row.tsx`: `Row({ item, card, words, density, timeZone, expanded, onToggle })` where `item: BoardItem`, `card: CardEnvelope`, `words: Words`, `density: Density`, `timeZone?: string` (passed to `Intl.DateTimeFormat` for clock times), `expanded: boolean`, `onToggle(): void`.
Anatomy left to right: icon (decorative `aria-hidden` glyph from `item.icon`, a simple placeholder is fine), name + meaning, meter, value + unit, state shape + word (use `STATE_SHAPE`), freshness.
- Value: `card.values[item.fields[0].key]?.text`, else "—". A value whose `text` is exactly "unknown" with no `raw` is missing: show "—" too (C2.1). `"none"` (empty list) is shown as is. Unit from `item.fields[0].unit`, shown only when a value exists. (`not_configured` cards are never rows on Home; do not handle them.)
- Meaning: `meaning.short` for Short, `meaning.full` for Full, hidden for Minimal.
- Freshness: when `card.freshness === "stale"` show `as of HH:MM` (24h, from `last_good_at`, else `observed_at`; if neither exists show nothing). Minimal shows freshness only when stale. Full shows "Current" when current.
- Frozen = `freshness === "stale"` or `source_state` is unavailable/stale.
- The row's name area is one `<button aria-expanded={expanded}>` that calls `onToggle`. The row is a `<li>`.
- When `expanded`, render directly after the button a `<section role="region" aria-label="{title} details">` containing, in this order: the full meaning, the state shape + word, the detail (all `values` as "key: text"), the freshness text, a `<details>` whose `<summary>` is "Technical evidence" and whose body lists request_id, method, path, status_code, duration_ms, error_class, note (only those present; never anything else), then a link "Open in Connect" (href `#connect`). The `<details>` has `open` when `density === "detailed"`.
- Slim density: when `density === "calm"` and the item is in the quiet group the caller handles folding; you only need to keep rows compact via a `fd-row--slim` class when `item.size === "S"`.
Styles go in `ui/src/fd/fd.css` under a `/* row */` comment (shared file: append, do not overwrite).

Acceptance: `cd ui && npx vitest run --project unit src/test/fd-row.test.tsx`
