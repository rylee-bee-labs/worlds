# Project Identity

Project Worlds is a personal project by Rylee Hulgan. This page
describes how the name is used and how forks should distinguish
themselves.

## The official project

- Canonical source: `https://github.com/rylee-bee-labs/worlds`
- Maintainer of record: Rylee Hulgan (the author)
- Official communication channels: GitHub issues and pull requests
  on the canonical repository

Nothing else is "official Project Worlds" — not a fork, not a
re-packaged distribution, not a hosted service, not a tutorial
site. If you encounter something claiming to be official but not
hosted under the canonical URL above, that claim is incorrect.

## You are welcome to fork

You may fork, modify, and redistribute Project Worlds under its
license (see `LICENSE`). You may build commercial products on top
of it.

When you do, please use a distinct name for substantially modified
versions and do not imply endorsement by, or affiliation with, the
official project. Examples of acceptable fork naming:

- "Project-Worlds-fork" or "Project-Worlds-something" for a light
  modification
- A completely different name for a substantial fork or rewrite

Examples of unacceptable naming:

- "Official Project Worlds" or "Project Worlds by <your-org>" for
  a non-canonical fork
- "Project-Worlds-Cloud" / "Project-Worlds-Enterprise" when the
  offer is not from the maintainer of record
- Using the Project Worlds name to market an unrelated service

## Trademarks

"Project Worlds" and "Personal World" (the in-environment companion

grant. No ® or ™ is asserted.

Nothing in this document grants you permission to use the
"Rylee-Bee" or "Rylee Hulgan" names for endorsement. Please use
your own name and identity in your fork.

## Privacy boundary

A fresh public Project Worlds checkout holds the generic
application, public design contracts, and approved showcase
artwork. It does NOT contain Rylee's personal journals, deployment
configurations, provider credentials, operational logs, or any
state tied to Rylee's specific environment. See `SECURITY.md`
for the public-repository boundary contract.
