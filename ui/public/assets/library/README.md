# Library art (web sizes)

The Worlds Library's pictures (ART-REQUESTS §15, delivered 2026-09-27; painted with Wan 2.7 Pro, curated by Claude).

- `covers/{256,512}/<book>.webp`: one storybook cover per Worlds book, portrait 2:3, named after the book's file in `docs/library/` (e.g. `02-rooms.webp`). No text in the art; the page prints the title.
- `shelves/shelf-<look>.webp` (1536 × 512) and `shelf-<look>-768.webp`: a wide header per shelf look (`scifi-storybook`, `hive-corporate`, `vefr`), with transparent edges.
- Sol reading is with the crew: `../crew/{256,512}/sol-reading.webp`.

Masters: `design/assets/library/covers/`, `design/assets/library/shelves/` (WebP, quality 92). The original PNGs and the prompts are kept in the estate's media library.
